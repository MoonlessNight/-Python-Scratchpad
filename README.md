# 🧪 Python Scratchpad

Un espacio personal de aprendizaje, práctica y experimentación rápida en Python. Este repositorio reúne scripts pequeños, fragmentos de código y ejercicios puntuales orientados al autoaprendizaje y la lógica de programación. No está diseñado ni optimizado para entornos de producción, pero es totalmente funcional.

---

## 📂 Estructura del Repositorio

| Carpeta | Descripción |
| :--- | :--- |
| `automatizaciones/` | Scripts para tareas repetitivas (manejo de archivos, web scraping simple, etc.). |
| `ejercicios_logica/` | Algoritmos, retos de código y ejercicios de lógica básica/intermedia. |
| `miniproyectos/` | Herramientas en consola (CLI) y pequeñas aplicaciones estructuradas. |
